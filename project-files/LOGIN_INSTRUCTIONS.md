## Настройка базы данных

1. Откройте MySQL (например, через phpMyAdmin или MySQL Workbench)
2. Выполните SQL-скрипт из файла `setup_users.sql`
3. Таблица `users` будет создана автоматически
4. Пользователи добавятся с хешированными паролями (SHA-256)

## Если вход не работает

Проверьте:
1. Запущен ли MySQL сервер
2. Правильная ли строка подключения в `LoginForm.cs`:
   ```csharp
   string connectionString = "SERVER=localhost;DATABASE=sewingfactory;UID=root;PASSWORD=1234";
   ```
3. Существует ли база данных `sewingfactory`
4. Выполнен ли SQL-скрипт `setup_users.sql`

## Добавление новых пользователей

Чтобы добавить нового пользователя, выполните в MySQL:

```sql
INSERT INTO users (username, password_hash, role, full_name, is_active) 
VALUES (
    'new.user', 
    SHA2('Password123!', 256), 
    'Staff', 
    'Фамилия Имя Отчество - Должность', 
    TRUE
);
```

## Безопасность

- Все пароли хранятся в виде SHA-256 хешей
- Используются параметризованные запросы (защита от SQL-инъекций)
- Логирование всех входов в файл ActivityLog.txt
